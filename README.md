# Pulse

Pulse is an offline Android music player focused on simplicity, performance and a clean interface. It plays the songs stored on your device, without accounts, ads or an internet connection.

## Features

- Offline music playback from the device library
- Mini player on the home screen and a full player screen
- The last played track is restored on app start
- Shuffle and repeat modes (repeat all, repeat one)
- Media notification with play/pause, next/previous and a close button
- Tapping the notification opens the player screen
- Auto-play after changing a track
- Track duration on the home screen
- Album covers and colors that adapt to each track
- Sorting by title or date added
- Runtime permission handling with an explanation screen
- Checks GitHub Releases for new versions and downloads the APK directly

## Built with

- Kotlin and Java
- Android SDK (minimum Android 8.0, API 26)
- AndroidX Media3 (ExoPlayer)
- RecyclerView and Material Components
- DataStore for settings
- Retrofit for update checks

## Download

Download the latest APK from the [Releases](https://github.com/Setyann/Pulse/releases/latest) page.

## Installation

1. Download the latest APK from **Releases**.
2. Install the APK on your Android device.
3. Android may show a security warning, because the app is distributed outside Google Play. Confirm the installation to continue.
4. Launch Pulse and allow access to music on your device.
